# Quickstart: Post-Start play chrome

1. Open Mini App from `@tgquarto_bot` (hard-refresh after Pages deploy).
2. On home: confirm Session rules (Miss/Pie) visible; language matches Telegram.
3. Press **Start** / **Начать партию**.
4. Expect waiting/share UI **without** Session rules and **without** achievements under the match.
5. Leave / new match → home rules return.
