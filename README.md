# Quarto

Игра «Кварто» в Telegram на двоих: challenge-карточка, партия в Mini App.

- Бот: [@tgquarto_bot](https://t.me/tgquarto_bot)
- Mini App: https://buravchik.github.io/quarto/

## Правила

### Состав

Доска 4×4. Шестнадцать разных фигур. У каждой фигуры четыре признака, у каждого признака ровно два значения:

| Признак | Значения |
| --- | --- |
| Цвет | светлая / тёмная |
| Высота | высокая / низкая |
| Форма | круглая / квадратная |
| Верх | полая / сплошная |

### Как ходить

Это give-and-place: фигуру для постановки выбирает **соперник**.

1. Игрок A выбирает одну фигуру из пула (ещё не стоящих на доске) и отдаёт её игроку B.  
2. Игрок B ставит эту фигуру на любую пустую клетку.  
3. Затем B выбирает следующую фигуру из пула и отдаёт её A.  
4. A ставит, выбирает фигуру для B — и так далее.

Кто открывает партию (первый отдаёт фигуру), определяется при старте матча после того, как оба сели за стол.

### Победа

Выигрыш — четыре фигуры в один ряд:

- по горизонтали, или  
- по вертикали, или  
- по одной из двух главных диагоналей,

у которых совпадает **хотя бы один** признак (например, все четыре светлые, или все высокие, или все круглые, или все полые — и любые другие совпадения по одному признаку).

Победа не засчитывается «сама по себе», пока кто-то стоит на доске. Нужно **объявить «Кварто!»** и указать именно эти четыре клетки. Сервер проверяет, что набор легален по правилам текущей партии (включая Miss ниже).

### Ничья

Если все 16 клеток заняты и объявлять легальное Кварто уже некому — партия заканчивается ничьей автоматически. Отдельно «объявлять ничью» не нужно.

### Miss

Перед стартом создатель слота может включить Miss. Настройка фиксируется, когда соперник присоединяется.

**Miss выключен — Persistent**

- Объявить Кварто можно только **сразу после своей постановки**, пока ты ещё не отдал следующую фигуру сопернику.  
- Четыре клетки в объявлении должны включать клетку, куда ты только что поставил.  
- Если отдал фигуру, не объявив — своё окно на эту постановку закрыто. Соперник **не** может заявить твоё Кварто «за тебя», пока держит полученную фигуру.  
- Законченные линии сами по себе не помечаются мёртвыми (в отличие от Void): они просто ждут, пока снова не сложится правило «объявить сразу после своего place» через клетку этой постановки.

**Miss включён — Void**

- После своей постановки объяви Кварто **до hand-off** (пока не отдал следующую фигуру).  
- Не объявил — у соперника есть окно: он может объявить Кварто на эту линию **до своей постановки** (и выиграть).  
- Если соперник поставил фигуру, так и не заявив, пропущенные линии через ту клетку **умирают** и больше не принимаются.  
- И при объявлении, и при проверке смотрят только линии **через клетку только что поставленной фигуры**.

### Pie Rule

Отдельная галочка перед стартом (по умолчанию выключена). Тоже локается на join.

После **самой первой** постановки фигуры на доску второй игрок выбирает одно из двух:

- забрать открытие (стать тем, кто дальше ведёт себя как открывающий), или  
- остаться вторым.

### Таймаут и реванш

Если игрок слишком долго не ходит (8 часов с момента, когда ход стал его), ожидающий может забрать победу по таймауту.

После окончания партии можно предложить, принять или отклонить реванш. Miss и Pie для новой партии копируются с предыдущей.

### Карточка

Одна challenge-карточка может держать до восьми независимых партий 1v1. Кнопка Open Mini App открывает предпочтительный слот: сначала waiting, иначе активный, иначе первый в списке.

## Разработка

Спеки: `specs/`. Конституция: `.specify/memory/constitution.md`.  

```bash
cp .env.example .env
npm ci
npm test
npm run build
npm run bot:start
npm run dev
```

API / webhook: Cloud Run `quarto-bot`, переменные в `.env.example`.
