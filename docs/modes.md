# Другие режимы Кварто

Сейчас в боте — классика 4×4 (см. [README](../README.md)). Ниже — режимы, которые планируем добавить. База та же: доска, фигуры с признаками, объявление «Кварто!» с указанием клеток. Меняется только то, что написано в разделе режима.

Из каждой группы совместимости в одной партии берут **не больше одного** режима:

| Группа | Режимы |
| --- | --- |
| Скольжение | Quarto+ · Shift |
| Обёртка | Wrap Diagonals · Wrap Squares · Torus |
| Квадраты | Comp 1 · Any Square |
| Полярность победы | Classic · Anti-Quarto |
| Сколько признаков | Classic (≥1) · Double (≥2) |
| Как выбирают фигуру | Classic give · Self-Pick · Blind · Draft · Ban |
| Размер / раскладка | 4×4 · 3×3 · 5×5 · 6×6 · 8×8 · 3D · Starburst · Gridless · … |

---

## Семья A — признаки и выбор фигуры

### Beginner Traits-N

Как в классике, но в партии считают только **N** признаков из четырёх (1, 2 или 3). Остальные признаки на фигурах есть, но для победы их не смотрят. Какие именно оси активны — выбирают перед стартом.

### Self-Pick

Нет give-and-place. На своём ходу игрок **сам** берёт фигуру из пула и **сам** ставит её. Затем ход соперника.

При идеальной игре второй обычно выигрывает — этот режим лучше включать вместе с Pie Rule.

### Five-Trait

Доска по-прежнему **4×4** (16 клеток). Фигур **32**: к четырём признакам добавляется пятый (название в UI ещё выберем). На доске одновременно не больше 16 фигур; остальные ждут в пуле. Победа — как в классике: четыре в ряд с общим значением по **хотя бы одному** из пяти признаков + объявление.

### Double Quarto

Победа только если у четырёх фигур в наборе совпадают **не меньше двух** признаков сразу (например, все светлые **и** все высокие). Один общий признак — ещё не Кварто.

### Anti-Quarto

Кто **закрыл** выигрышный набор своей постановкой — **проигрывает**. Остальное как в классике (или как в выбранном геометрии-режиме). Как именно фиксировать проигрыш (автоматом при place или только после объявления) — уточним в спеке; идея: не дать выиграть, промолчав.

## Семья B — геометрия на 4×4

К классическим линиям (4 ряда + 4 столбца + 2 диагонали) добавляются другие четвёрки клеток. Объявление то же: указать четыре клетки с общим признаком.

### Comp 1

Дополнительно считаются **девять** смежных квадратов 2×2 (каждый угол квадрата — клетка доски).

### Any Square

Дополнительно — **ровно 20** квадратов из четырёх клеток (не параллелограммы и не «прямоугольники не-квадраты»):

| Класс | Сколько |
| --- | --- |
| смежные 2×2 | 9 |
| углы клеток внутри блоков 3×3 | 4 |
| четыре угла всей доски 4×4 | 1 |
| ромбы, повёрнутые на 45° | 4 |
| косые «конём» (knight-skew) | 2 |
| **Всего** | **20** |

Comp 1 — подмножество (только девять 2×2). Comp 1 и Any Square вместе в одной партии не берут.

### Wrap Diagonals

Доска как тор по диагоналям: линии «переезжают» через край. Добавляется **6** wrap-диагоналей (по Magliery Set Quarto).

### Wrap Squares

То же для квадратов 2×2 через край: **7** wrap-квадратов, включая вариант из четырёх углов доски.

### Torus

На 4×4 это классические линии **плюс** Wrap Diagonals **плюс** Wrap Squares. Отдельные Wrap рядом с Torus не включают.

## Семья C — ход и память

### Blind

В начале каждому втайне раздают по **8** фигур. Игрок видит только **свой** пул. Отдавать и ставить можно только из того, что у тебя на руках (точные детали hand-off — в спеке; это не Quarto Access с повязкой).

### Quarto+

После постановки фигуры игрок **может** (не обязан) сдвинуть **одну** уже стоящую фигуру на соседнюю **пустую** клетку **по горизонтали или вертикали** (не по диагонали). Потом — обычный hand-off / объявление по правилам Miss.

### Shift

Раз за всю партию, **до** своей постановки, игрок может сдвинуть одну фигуру на соседнюю пустую клетку ортогонально, затем ставит полученную фигуру. С Quarto+ в одной партии не берут.

### Ban A / Ban B

Модификаторы give-and-place при отдаче фигуры:

- **Ban A** — отдающий называет запрет по признаку (например, «не ставь на светлую клетку…» — точная формулировка в спеке): на этот place действуют ограничения.
- **Ban B** — отдающий запрещает **одну пустую клетку**: на неё эту фигуру ставить нельзя.

### Draft

Вместо одной фигуры в руке — постоянно **три**:

1. Добрать одну из пула (стало 3).  
2. Отдать сопернику **одну из трёх**.  
3. Соперник ставит полученную; у отдающего в руке снова две, пока снова не доберёт.

Каркас как в Aces and Faces / BGG cards-варианте.

### Face-Down Extreme

Фигуры до постановки видны лицом; на доске кладутся **рубашкой вниз**. Объявить Кварто можно, только если считаешь, что линия из четырёх **сплошных** или четырёх **полых**. Для проверки переворачивают; ошибка — проигрыш. Как считать остальные признаки — допишем в спеке (в исходном предложении это мутно).

## Семья D — другие размеры и раскладки

### 5×5 (Penta / Hybrid)

Доска 5×5, **32** фигуры (пять признаков). Семь фигур остаются вне партии (как именно отбирают — в спеке). Победа: пять в ряд с общим признаком и/или гибридные условия (например, четыре подряд с ≥2 признаками) — зафиксируем отдельно. Это **не** Icehouse Quinto.

### 6×6 + препятствия

Доска 6×6. В начале каждый игрок ставит **по два** блока-препятствия на пустые клетки; на них фигуры не ставят. Дальше — обобщение классики на это поле (длина линии и win-sets — в спеке).

### 8×8 Six-Trait

**64** фигуры, **шесть** бинарных признаков (пятого на 8×8 не хватает). Правило победы «восемь в ряд с общим признаком» — наше (HOUSE): в математических статьях есть только размерность набора, не rulebook.

### 3×3 Ternary

**9** клеток, **9** фигур. Два признака, у каждого **три** значения (не два). Победа: три в ряд с одним общим значением признака + объявление.

### 3D / 4D

- **3D:** куб 4×4×4, обычно 64 фигуры / 6 признаков. Выигрышные четвёрки по осям и пространственным диагоналям — наши маски (HOUSE), пока нет внешнего списка.  
- **4D:** гиперкуб. Playable правило победы во внешних текстах не зафиксировано — любое полное правило будет HOUSE.

### Starburst

Особая раскладка клеток (Magliery). Выигрышные наборы **фиксированы**: 4 ряда + 8 внутренних дуг + 8 внешних дуг + 8 клиньев = **28** наборов. Координаты клеток выпишем в спеке по схеме.

### Gridless

Нет жёсткой сетки 4×4: фигуры ставят на плоскость так, чтобы вся группа **не была шире и не длиннее четырёх** фигур. Кварто — четыре в линию (или иной win-set из спеки) с общим признаком.

### Placement-Dictates-Board

Идея: ходы сами задают, где угол / край / центр. Внешний текст обрывается — **к игре не готов**, пока не перепишем правила целиком.

## Отдельные типы партии

Это не «галочка mode» на обычном 1v1-слоте, а другой формат стола:

| Тип | Как играют |
| --- | --- |
| N игроков (pass-left) | Отдал фигуру соседу слева → тот ставит → отдаёт дальше |
| Команды 4p | Две пары; **партнёры сидят напротив** |
| 3p miss house | Если ряд не заметили вовремя — победа тому, кто **отдал** фигуру до появления ряда |
| Elimination | Кто отдал фигуру, закрывшую Кварто, выбывает; доска сбрасывается; побеждает последний. Новую партию начинает поставивший последнюю фигуру; если играют «с жизнями» — начинает потерявший жизнь |
| Solitaire | Один игрок: заполнить доску **без** Кварто (иногда с кубиком для выбора клетки) |

В Telegram по умолчанию остаётся **1v1**. Третьего в уже идущую партию на двоих не сажают.

Отдельно (уже не «тип партии» из таблицы): **игра с компьютером** — та же классика 1v1, второй слот занимает бот. Это не Solitaire.
